よくある質問

📢 新作脱出ゲームの通知を受け取る方法は？

アプリ内で通知をオンに設定してください。新しい脱出ゲームがリリースされるとプッシュ通知でお知らせします。

🔍 興味のある脱出ゲームを効率的に探すには？

ランキング機能で人気や評価の高いゲームをチェックしたり、検索・絞り込み機能でゲーム名、ジャンル、公開日などの条件を指定して探すことができます。

💰 アプリは無料で利用できますか？

基本機能は無料でご利用いただけます。有料プランでは広告の完全非表示などの特典があります。

使い方

  1. アプリをダウンロードして起動します。
  2. 通知をオンに設定します。
  3. 新作ランキングや検索から気になる脱出ゲームを探します。
  4. 詳細情報をチェックして、ストアからゲームをダウンロードしてすぐにプレイを開始します。

本アプリは非公式アプリであり、特定のゲーム開発元やプラットフォームとは関係ありません。掲載情報はストアから取得しているため、情報が古くなっている場合があります。最新の情報は各ストアでご確認ください。
