## 绝不错过彩虹社直播！直播与日程通知应用 V-Seek

**V-Seek** 是一款为彩虹社粉丝制作的非官方应用。它能帮助您快速查看直播和日程，通过实时通知防止您错过直播，并让您搜索精彩片段和合作视频。凭借流畅的性能和直观的用户界面，它将您的彩虹社生活升级为更舒适、更有趣的体验。

## 主要功能：掌握每个彩虹社直播

- **直播日程显示**: 在一个地方查看彩虹社Liver的直播、即将开始和已存档的直播。
- **实时通知**: 接收突袭式直播或突发合作的推送通知，让您绝不错过您的推直播。
- **频道隐藏**: 隐藏您不感兴趣的频道，以自定义您的时间线。
- **Holodex API Key 支持**: 设置您自己的 API Key，以提高稳定性并更可靠地获取最新的直播数据。
- **图片放大**: 长按缩略图、频道图标或横幅图片，以放大并详细查看。
- **自定义显示模式**: 根据您的喜好，在大型缩略图模式、列表模式、紧凑模式等之间切换。
- **视频质量设置**: 根据您的设备和网络，选择性能优先、平衡或高质量。

## 常见问题 (FAQ)

### 📢 如何接收直播通知？
点击每个频道上的铃铛图标，并将其设置为“开启”，即可在直播开始时收到通知。

### 🎬 如何隐藏我不感兴趣的频道？
前往 **设置 > 隐藏频道** 并单独管理它们。只保留您关心的频道。

### 🌐 如果我看到错误该怎么办？
默认情况下，应用使用共享的 Holodex API Key，该键具有访问限制。设置您自己的 Holodex API Key 将提高稳定性和数据新鲜度。前往 **设置 > 设置 Holodex API Key** 进行配置。

### 📺 我不喜欢广告。我可以移除它们吗？
是的。广告支持应用，但您可以通过应用内购买移除它们，以获得无压力的体验。

## V-Seek 的推荐设置

1. **启用通知**: 点击您推的频道上的铃铛图标，以确保您收到直播提醒。
2. **隐藏频道**: 过滤掉您不感兴趣的频道，并建立您自己的自定义直播列表。
3. **调整视频质量**: 根据您的网络和设备，选择性能、平衡或高质量。
4. **设置 Holodex API Key**: 通过设置您自己的 API Key 来提高稳定性并减少错误。
