常见问题 (FAQ)

如何创建QR码？

从您的浏览器或其他应用程序分享您想要分享的URL或文本到“QR Code Share”，或直接在应用程序内输入文本，然后点击“创建QR码”按钮。

我可以保存创建的QR码吗？

是的，您可以将创建的QR码保存为图片到您的设备。您也可以直接分享到LINE或电子邮件等其他应用程序。

如何更改主题？

从应用程序的设置屏幕中选择“主题设置”，然后选择您喜欢的主题。

如何设置 / 如何使用

  1. 从浏览器或备忘录应用程序等选择您想要分享的URL或文本，然后点击“分享”按钮。
  2. 从分享菜单中选择“QR Code Share”。
  3. 应用程序将启动，并将分享的信息显示为QR码。
  4. 在“分享”选项卡中，您可以保存QR码图片或分享到其他应用程序。
  5. 若要手动创建QR码，请在“输入”选项卡中输入文本，然后点击“创建QR码”按钮。
