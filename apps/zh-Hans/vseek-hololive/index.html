常见问题 (FAQ)

📢 如何启用通知？

点击频道上的铃铛图标并将其设置为“ON”，即可在直播开始时立即收到通知。

🎬 我可以隐藏我不感兴趣的频道吗？

是。前往设置 > 隐藏频道以单独管理并只保留您想要的频道。

🌐 为什么我会看到错误或过时的数据？

应用默认使用共享的 Holodex API，该 API 有限制。设置您自己的 API 密钥可提高稳定性并确保您始终获得最新的直播信息。前往设置 > Holodex API 密钥进行设置。

📺 如何移除广告？

广告支持应用的开发，但您可以通过应用内购买移除广告，以获得更流畅的体验。

🔍 如何放大缩略图或频道图标？

只需长按任何缩略图、频道图标或横幅图像即可放大。
