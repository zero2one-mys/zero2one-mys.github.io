## 니지산지 스트림을 다시는 놓치지 마세요! 라이브 및 스케줄 알림 앱 V-Seek

**V-Seek**은 니지산지 팬들을 위해 만들어진 비공식 앱입니다. 라이브 스트림과 스케줄을 빠르게 확인할 수 있도록 돕고, 실시간 알림으로 스트림을 놓치는 것을 방지하며, 하이라이트와 콜라보 영상을 검색할 수 있게 해줍니다. 부드러운 성능과 직관적인 UI로 니지산지 생활을 더 편안하고 즐겁게 업그레이드합니다.

## 주요 기능: 모든 니지산지 스트림을 놓치지 마세요

- **스트림 스케줄 표시**: 니지산지 라이버의 라이브, 예정 및 보관된 스트림을 한 곳에서 볼 수 있습니다.
- **실시간 알림**: 깜짝 게릴라 스트림이나 갑작스러운 콜라보에 대한 푸시 알림을 받아 오시의 라이브를 절대 놓치지 마세요.
- **채널 숨기기**: 관심 없는 채널을 숨겨 자신만의 타임라인을 맞춤 설정할 수 있습니다.
- **Holodex API 키 지원**: 안정성을 향상시키고 최신 스트림 데이터를 더 안정적으로 가져오기 위해 자신만의 API 키를 설정하세요.
- **이미지 확대**: 썸네일, 채널 아이콘 또는 배너 이미지를 길게 눌러 확대하고 자세히 볼 수 있습니다.
- **맞춤형 표시 모드**: 선호도에 따라 큰 썸네일 모드, 목록 모드, 컴팩트 모드 등으로 전환할 수 있습니다.
- **비디오 품질 설정**: 장치 및 네트워크에 맞춰 성능 우선, 균형 또는 고품질 중에서 선택할 수 있습니다.

## 이 앱의 장점

- **스트림 놓침 없음**: 알림으로 오시의 라이브 순간을 실시간으로 포착하세요.
- **효율적인 정보 수집**: 가벼운 성능과 맞춤 설정 가능한 보기로 필요한 정보에 빠르게 액세스할 수 있습니다.
- **편안한 오시 지원**: 원치 않는 콘텐츠를 제거하고 자신만을 위한 맞춤형 시청 환경을 만드세요.

## 추천 대상

- 니지산지 라이브 스트림과 스케줄을 빠르게 확인하고 싶은 팬
- 오시의 방송을 절대 놓치고 싶지 않은 사람
- 하이라이트 클립과 콜라보 영상을 한 곳에서 확인하고 싶은 시청자
- 관련 없는 채널을 숨기고 더 깔끔한 앱 경험을 즐기고 싶은 사용자
- 간단하고 사용하기 쉬운 앱을 찾는 니지산지 팬

## 자주 묻는 질문 (FAQ)

### 📢 스트림 알림은 어떻게 받나요?
각 채널의 종 모양 아이콘을 탭하고 스트림이 시작될 때 알림을 받으려면 "켜기"로 설정하세요.

### 🎬 관심 없는 채널은 어떻게 숨길 수 있나요?
**설정 > 채널 숨기기**로 이동하여 개별적으로 관리하세요. 관심 있는 채널만 유지하세요.

### 🌐 오류가 보이면 어떻게 해야 하나요?
기본적으로 앱은 접근 제한이 있는 공유 Holodex API 키를 사용합니다. 자신만의 Holodex API 키를 설정하면 안정성과 데이터 최신성이 향상됩니다. **설정 > Holodex API 키 설정**으로 이동하여 구성하세요.

### 📺 광고가 싫어요. 제거할 수 있나요?
네. 광고는 앱을 지원하지만, 스트레스 없는 경험을 위해 인앱 구매를 통해 제거할 수 있습니다.

## V-Seek 권장 설정

1. **알림 활성화**: 오시 채널의 종 모양 아이콘을 탭하여 스트림 알림을 받도록 설정하세요.
2. **채널 숨기기**: 관심 없는 채널을 필터링하고 자신만의 맞춤 스트림 목록을 만드세요.
3. **비디오 품질 조정**: 네트워크 및 장치에 따라 성능, 균형 또는 고품질 중에서 선택하세요.
4. **Holodex API 키 설정**: 자신만의 API 키를 구성하여 안정성을 향상시키고 오류를 줄이세요.
