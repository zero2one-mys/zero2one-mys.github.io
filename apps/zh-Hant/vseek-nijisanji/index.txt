- **直播行程顯示**: 在一個地方查看彩虹社Liver的直播、即將開始和已存檔的直播。

- **頻道隱藏**: 隱藏您不感興趣的頻道，以自訂您的時間軸。
- **Holodex API Key 支援**: 設定您自己的 API Key，以提高穩定性並更可靠地獲取最新的直播資料。
- **圖片放大**: 長按縮圖、頻道圖示或橫幅圖片，以放大並詳細檢視。
- **自訂顯示模式**: 根據您的喜好，在大型縮圖模式、列表模式、緊湊模式等之間切換。
- **視訊品質設定**: 根據您的設備和網路，選擇效能優先、平衡或高品質。

## 常見問題 (FAQ)

### 📢 如何接收直播通知？
點擊每個頻道上的鈴鐺圖示，並將其設定為「開啟」，即可在直播開始時收到通知。

### 🎬 如何隱藏我不感興趣的頻道？
前往 **設定 > 隱藏頻道** 並單獨管理它們。只保留您關心的頻道。

### 🌐 如果我看到錯誤該怎麼辦？
預設情況下，應用程式使用共享的 Holodex API Key，該鍵具有存取限制。設定您自己的 Holodex API Key 將提高穩定性和資料新鮮度。前往 **設定 > 設定 Holodex API Key** 進行配置。

### 📺 我不喜歡廣告。我可以移除它們嗎？
是的。廣告支持應用程式，但您可以透過應用程式內購買移除它們，以獲得無壓力的體驗。

1. **啟用通知**: 點擊您推的頻道上的鈴鐺圖示，以確保您收到直播提醒。
