常見問題 (FAQ)

📢 如何啟用通知？

點擊頻道上的鈴鐺圖示並將其設定為「ON」，即可在直播開始時立即收到通知。

🎬 我可以隱藏我不感興趣的頻道嗎？

是。前往設定 > 隱藏頻道以單獨管理並只保留您想要的頻道。

🌐 為什麼我會看到錯誤或過時的數據？

應用程式預設使用共享的 Holodex API，該 API 有限制。設定您自己的 API 密鑰可提高穩定性並確保您始終獲得最新的直播資訊。前往設定 > Holodex API 密鑰進行設定。

📺 如何移除廣告？

廣告支持應用程式的開發，但您可以透過應用程式內購買移除廣告，以獲得更流暢的體驗。

🔍 如何放大縮圖或頻道圖示？

只需長按任何縮圖、頻道圖示或橫幅圖像即可放大。

設定與使用

  1. 下載應用程式: 從 App Store 安裝「V-Seek」。
  2. 註冊您的推: 添加您最喜歡的 Hololive 藝人以建立您的個人化時間軸。
  3. 啟用通知: 點擊每個頻道上的鈴鐺圖示以開啟直播提醒。
  4. 自訂顯示: 在設定中調整影片品質、佈局樣式和隱藏頻道。
  5. 可選：API 密鑰設定: 為了獲得最佳穩定性和最快的更新，請設定您自己的 Holodex API 密鑰。
