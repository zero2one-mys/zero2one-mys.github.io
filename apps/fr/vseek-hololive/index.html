Foire aux questions (FAQ)

📢 Comment activer les notifications ?

Appuyez sur l'icône en forme de cloche sur une chaîne et réglez-la sur « ON » pour être averti dès que les streams commencent.

🎬 Puis-je masquer les chaînes qui ne m'intéressent pas ?

Oui. Allez dans Paramètres > Masquer les chaînes pour les gérer individuellement et ne conserver que celles que vous souhaitez.

🌐 Pourquoi est-ce que je vois des erreurs ou des données obsolètes ?

L'application utilise par défaut l'API Holodex partagée, qui a des limites. La configuration de votre propre clé API améliore la stabilité et garantit que vous obtenez toujours les dernières informations de stream. Allez dans Paramètres > Clé API Holodex pour la configurer.

📺 Comment puis-je supprimer les publicités ?

Les publicités soutiennent le développement de l'application, mais vous pouvez les supprimer via un achat intégré à l'application pour une expérience plus fluide.

🔍 Comment zoomer sur les miniatures ou les icônes de chaîne ?

Appuyez simplement longuement sur n'importe quelle miniature, icône de chaîne ou image de bannière pour l'agrandir.

Configuration et utilisation

  1. Téléchargez l'application: Installez « V-Seek » depuis l'App Store.
  2. Enregistrez vos oshis: Ajoutez vos talents Hololive préférés pour créer votre chronologie personnalisée.
  3. Activez les notifications: Appuyez sur l'icône en forme de cloche sur chaque chaîne pour activer les alertes de stream en direct.
  4. Personnalisez l'affichage: Ajustez la qualité vidéo, le style de mise en page et les chaînes masquées dans les paramètres.
  5. Facultatif: Configuration de la clé API: Pour une meilleure stabilité et des mises à jour plus rapides, configurez votre propre clé API Holodex.
