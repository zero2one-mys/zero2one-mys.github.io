תכונות עיקריות: תיהנו משידורי YouTube של Hololive בנוחות רבה יותר

  • תצוגת לוח זמנים של שידורים בזמן אמת: בדקו באופן מיידי את לוח הזמנים המלא של Hololive YouTube ברגע שתפתחו את האפליקציה. ביצועים חלקים מבטיחים שימוש ללא לחץ גם בזמנים עמוסים.
  • מועדפים והתראות מותאמות אישית: רשמו רק את האושיס שלכם וקבלו התראות פוש על שידורי גרילה מפתיעים או שיתופי פעולה. ניתן לכבות התראות לא רצויות לחוויה מותאמת אישית.
  • סינון וחיפוש וידאו: עברו בין קטגוריות כמו "שידורים חיים", "ארכיונים", "קליפים" ו"שיתופי פעולה". הסתירו ערוצים שאינם מעניינים אתכם לרשימה נקייה יותר.
  • עיצוב פשוט ואינטואיטיבי: החליפו סוגי שידורים בלחיצה אחת. תמונות ממוזערות ותמונות ערוץ ניתנות להגדלה לצפייה מפורטת.
  • התראות פוש מיידיות לשידורי גרילה: קבלו התראות בזמן אמת כאשר האושי שלכם עולה לשידור חי – לעולם אל תחמיצו רגע חשוב שוב.
  • הסתרת ערוצים: הסתירו ערוצים בודדים כדי ליצור רשימה מותאמת אישית משלכם.
  • הגדרות איכות וידאו: בחרו בין עדיפות ביצועים, מאוזן או איכות גבוהה לחווית הצפייה הטובה ביותר בהתאם לרשת שלכם.
  • מצבי תצוגה ניתנים להתאמה אישית: בחרו מבין פריסות של תמונה ממוזערת גדולה, רשימה, קומפקטי, קומפקטי 2 עמודות או קומפקטי 3 עמודות.
  • תצוגת וידאו לחברים בלבד: הישארו מעודכנים בשידורים לחברים בלבד כדי שלא תפספסו תוכן בלעדי.
  • תמיכה במפתח API של Holodex: הגדירו מפתח API משלכם כדי לעקוף מגבלות משותפות, לשפר את היציבות ולשמור על מידע השידור שלכם תמיד מעודכן.
  • זום תמונה: לחצו לחיצה ארוכה על תמונות ממוזערות, סמלי ערוץ או באנרים כדי להציג אותם בפירוט.
  • אפשרות הסרת פרסומות: הסירו פרסומות באמצעות רכישה בתוך האפליקציה לחוויה חלקה עוד יותר.

🎬 האם אני יכול להסתיר ערוצים שאינם מעניינים אותי?

כן. עברו אל הגדרות > הסתר ערוצים כדי לנהל אותם בנפרד ולשמור רק את אלה שאתם רוצים.

🌐 למה אני רואה שגיאות או נתונים מיושנים?

האפליקציה משתמשת כברירת מחדל ב-API המשותף של Holodex, שיש לו מגבלות. הגדרת מפתח API משלכם משפרת את היציבות ומבטיחה שתקבלו תמיד את מידע השידור העדכני ביותר. עברו אל הגדרות > מפתח API של Holodex כדי להגדיר אותו.

📺 איך אני יכול להסיר פרסומות?

פרסומות תומכות בפיתוח האפליקציה, אך ניתן להסיר אותן באמצעות רכישה בתוך האפליקציה לחוויה חלקה יותר.

🔍 איך אני מגדיל תמונות ממוזערות או סמלי ערוץ?

פשוט לחצו לחיצה ארוכה על כל תמונה ממוזערת, סמל ערוץ או תמונת באנר כדי להגדיל אותה.
