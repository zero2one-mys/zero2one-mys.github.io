Ngokusebenza kahle kanye ne-UI enembile, luthuthukisa impilo yakho ye-Nijisanji ukuze ibe ntofontofo futhi ijabulise kakhulu.

  • Ukufihla Iziteshi: Fihla iziteshi ongenaso isithakazelo kuzo ukuze wenze isikhathi sakho sibe ngesakho.
  • Ukusekelwa Kwe-Holodex API Key: Setha i-API key yakho ukuze uthuthukise ukuzinza futhi ulande idatha yakamuva yokusakaza ngokuthembekile.
  • Ukusondeza Isithombe: Cindezela isikhathi eside izithombe ezincane, izithonjana zesiteshi, noma izithombe zebhanela ukuze uzikhulise futhi uzibuke ngemininingwane.
  • Izindlela Zokubonisa Ezenziwe Ngokwezifiso: Shintsha phakathi kwemodi yesithombe esincane esikhulu, imodi yohlu, imodi encane, nokuningi kuye ngokuthanda kwakho.
  • Izilungiselelo Zekhwalithi Yevidiyo: Khetha phakathi kokuhamba phambili kokusebenza, okulinganiselwe, noma ikhwalithi ephezulu ukuze kufane nedivayisi yakho nenethiwekhi.

Izinzuzo Zalolu Hlelo Lokusebenza

  • Akukho Ukusakaza Okulahlekile: Thola izikhathi ezibukhoma ze-oshi yakho ngesikhathi sangempela ngezaziso.

  • Ukusekelwa Kwe-Oshi Okunethezekile: Susa okuqukethwe okungafuneki futhi udale indawo yokubuka eyenziwe yaba ngeyakho kuphela.

Imibuzo Ebuzwa Njalo (FAQ)

📢 Ngizithola kanjani izaziso zokusakaza?

Thepha isithonjana sensimbi esiteshini ngasinye bese usetha ku-“ON” ukuze uthole isaziso ngokushesha lapho ukusakaza kuqala.

🎬 Ngizifihla kanjani iziteshi engingenaso isithakazelo kuzo?

Iya ku-Izilungiselelo > Fihla Iziteshi bese uziphatha ngamunye. Gcina kuphela iziteshi ozikhathalelayo.

🌐 Yini okufanele ngiyenze uma ngibona amaphutha?

Ngokuzenzakalelayo, uhlelo lokusebenza lusebenzisa i-Holodex API key eyabiwe, enemithetho yokufinyelela. Ukusetha i-Holodex API key yakho kuzothuthukisa ukuzinza kanye nokusha kwedatha. Iya ku-Izilungiselelo > Setha i-Holodex API Key ukuze uyilungiselele.

📺 Angizithandi izikhangiso. Ngingazisusa?

Yebo. Izikhangiso zisekela uhlelo lokusebenza, kodwa ungazisusa ngokuthenga ngaphakathi nohlelo ukuze uthole isipiliyoni esingenaso ingcindezi.
