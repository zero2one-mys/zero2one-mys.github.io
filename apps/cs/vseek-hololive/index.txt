## Už nikdy nezmeškáte stream Hololive! Oznámení YouTube a správce rozvrhu – V-Seek

**V-Seek** je neoficiální aplikace vytvořená pro fanoušky Hololive, která poskytuje oznámení o streamování na YouTube, správu rozvrhu a vyhledávání videí.
Díky svému lehkému výkonu a intuitivnímu designu usnadňuje a zefektivňuje podporu vašeho oshi. Od živých streamů a archivů po nejdůležitější momenty, krátká videa a kolaborační videa, V-Seek podporuje celou vaši zkušenost s Hololive YouTube.

## Klíčové funkce: Užívejte si streamy Hololive YouTube pohodlněji

- **Zobrazení rozvrhu streamů v reálném čase**: Okamžitě zkontrolujte celý rozvrh Hololive YouTube, jakmile otevřete aplikaci. Hladký výkon zajišťuje bezstresové používání i v rušných časech.
- **Oblíbené a vlastní oznámení**: Zaregistrujte pouze své oshi a dostávejte push oznámení pro překvapivé "guerrilla" streamy nebo kolaborace. Nechtěná oznámení lze vypnout pro personalizovaný zážitek.
- **Filtrování a vyhledávání videí**: Přepínejte mezi kategoriemi jako „Živé streamy“, „Archivy“, „Klipy“ a „Kolaborace“. Skryjte kanály, které vás nezajímají, pro čistší seznam.
- **Jednoduchý, intuitivní design**: Přepínejte typy streamů jediným klepnutím. Miniatury a obrázky kanálů lze zvětšit pro detailní prohlížení.
- **Okamžitá push oznámení pro "guerrilla" streamy**: Buďte v reálném čase informováni, když váš oshi začne živý stream – už nikdy nezmeškáte důležitý okamžik.
- **Skrytí kanálů**: Skryjte jednotlivé kanály a vytvořte si vlastní seznam.
- **Nastavení kvality videa**: Vyberte si mezi prioritou výkonu, vyváženou nebo vysokou kvalitou pro nejlepší zážitek ze sledování v závislosti na vaší síti.
- **Přizpůsobitelné režimy zobrazení**: Vyberte si z rozložení velké miniatury, seznamu, kompaktního, kompaktního 2 sloupce nebo kompaktního 3 sloupce.
- **Zobrazení videí pouze pro členy**: Zůstaňte informováni o streamech pouze pro členy, abyste nezmeškali exkluzivní obsah.
- **Podpora Holodex API klíče**: Nastavte si vlastní API klíč, abyste obešli sdílené limity, zlepšili stabilitu a udrželi informace o streamech vždy aktuální.
- **Zoomování obrázků**: Dlouze stiskněte miniatury, ikony kanálů nebo bannery, abyste je prohlédli detailně.
- **Možnost odstranění reklam**: Odstraňte reklamy prostřednictvím nákupu v aplikaci pro ještě plynulejší zážitek.

## Výhody používání této aplikace

- **Už nikdy nezmeškáte streamy Hololive**: Oznámení a rozvrh v reálném čase vás udržují v obraze o aktivitách vašich oshi.
- **Efektivní podpora oshi**: Lehký a intuitivní uživatelské rozhraní usnadňuje sběr informací o streamech.
- **Plná přizpůsobitelnost**: Oblíbené, oznámení, skryté kanály, nastavení kvality a režimy zobrazení vytvářejí zážitek ze sledování přizpůsobený vám.
- **Okamžitá aktualizace**: S vlastním Holodex API klíčem se vyhnete sdíleným limitům a vždy získáte nejnovější data o streamech YouTube.

## Často kladené otázky (FAQ)

### 📢 Jak povolím oznámení?
Klepněte na ikonu zvonku na kanálu a nastavte ji na „ZAPNUTO“, abyste dostávali oznámení hned, jak streamy začnou.

### 🎬 Mohu skrýt kanály, o které nemám zájem?
Ano. Přejděte do **Nastavení > Skrýt kanály** a spravujte je jednotlivě a ponechte pouze ty, které chcete.

### 🌐 Proč vidím chyby nebo zastaralá data?
Aplikace standardně používá sdílené Holodex API, které má limity. Nastavení vlastního API klíče zlepšuje stabilitu a zajišťuje, že vždy získáte nejnovější informace o streamech. Přejděte do **Nastavení > Holodex API klíč** a nastavte jej.

### 📺 Jak mohu odstranit reklamy?
Reklamy podporují vývoj aplikace, ale můžete je odstranit prostřednictvím nákupu v aplikaci pro plynulejší zážitek.

### 🔍 Jak mohu zvětšit miniatury nebo ikony kanálů?
Jednoduše dlouze stiskněte jakoukoli miniaturu, ikonu kanálu nebo obrázek banneru, abyste ji zvětšili.

3. **Povolte oznámení**: Klepněte na ikonu zvonku na každém kanálu, abyste zapnuli upozornění na živé streamy.
4. **Přizpůsobte zobrazení**: Upravte kvalitu videa, styl rozložení a skryté kanály v nastavení.
5. **Volitelné: Nastavení API klíče**: Pro nejlepší stabilitu a nejrychlejší aktualizace si nastavte vlastní Holodex API klíč.
