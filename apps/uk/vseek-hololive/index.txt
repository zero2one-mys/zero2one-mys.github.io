## Ніколи не пропускайте трансляції Hololive! Сповіщення YouTube та менеджер розкладу – V-Seek

**V-Seek** – це неофіційний додаток, створений для фанатів Hololive, який надає сповіщення про трансляції на YouTube, управління розкладом та пошук відео.
Завдяки своїй легкій продуктивності та інтуїтивно зрозумілому дизайну, він робить підтримку вашого оші розумнішою та легшою. Від прямих трансляцій та архівів до основних моментів, коротких відео та спільних відео, V-Seek підтримує весь ваш досвід Hololive на YouTube.

## Основні функції: Насолоджуйтесь трансляціями Hololive на YouTube з більшим комфортом

- **Відображення розкладу трансляцій у реальному часі**: Миттєво перевіряйте повний розклад Hololive на YouTube, як тільки відкриваєте додаток. Плавна робота забезпечує використання без стресу навіть у напружені часи.
- **Вибране та користувацькі сповіщення**: Зареєструйте лише своїх оші та отримуйте push-сповіщення про несподівані партизанські трансляції або співпрацю. Небажані сповіщення можна вимкнути для персоналізованого досвіду.
- **Фільтрування та пошук відео**: Перемикайтеся між категоріями, такими як «Прямі трансляції», «Архіви», «Кліпи» та «Співпраця». Приховуйте канали, які вас не цікавлять, для чистішого списку.
- **Простий, інтуїтивно зрозумілий дизайн**: Перемикайте типи трансляцій одним дотиком. Мініатюри та зображення каналів можна збільшувати для детального перегляду.
- **Миттєві push-сповіщення про партизанські трансляції**: Отримуйте сповіщення в реальному часі, коли ваш оші виходить в ефір — ніколи більше не пропускайте важливий момент.
- **Приховування каналів**: Приховуйте окремі канали, щоб створити власний індивідуальний список.
- **Налаштування якості відео**: Вибирайте між пріоритетом продуктивності, збалансованою або високою якістю для найкращого перегляду залежно від вашої мережі.
- **Настроювані режими відображення**: Вибирайте з макетів Великий ескіз, Список, Компактний, Компактний 2-колонки або Компактний 3-колонки.
- **Відображення відео лише для учасників**: Будьте в курсі трансляцій лише для учасників, щоб не пропустити ексклюзивний контент.
- **Підтримка ключа API Holodex**: Встановіть власний ключ API, щоб обійти спільні обмеження, покращити стабільність та завжди оновлювати інформацію про ваші трансляції.
- **Збільшення зображення**: Довго натискайте на мініатюри, значки каналів або банери, щоб переглянути їх детально.
- **Опція видалення реклами**: Видаліть рекламу за допомогою покупки в додатку для ще більш плавного досвіду.

## Переваги використання цього додатка

- **Ніколи не пропускайте трансляції Hololive**: Сповіщення та розклад у реальному часі тримають вас у курсі діяльності ваших оші.
- **Ефективна підтримка оші**: Легкий та інтуїтивно зрозумілий інтерфейс користувача робить збір інформації про трансляції без стресу.

- **Миттєво оновлюйтеся**: Завдяки власному ключу API Holodex уникайте спільних обмежень та завжди отримуйте найновіші дані про трансляції YouTube.

## Часті запитання (FAQ)

### 📢 Як увімкнути сповіщення?
Торкніться значка дзвіночка на каналі та встановіть його на «УВІМКНЕНО», щоб отримувати сповіщення одразу, коли почнуться трансляції.

### 🎬 Чи можу я приховати канали, які мене не цікавлять?
Так. Перейдіть до **Налаштування > Приховати канали**, щоб керувати ними індивідуально та залишати лише ті, які ви хочете.

### 🌐 Чому я бачу помилки або застарілі дані?
Додаток за замовчуванням використовує спільний API Holodex, який має обмеження. Встановлення власного ключа API покращує стабільність та гарантує, що ви завжди отримуватимете найновішу інформацію про трансляції. Перейдіть до **Налаштування > Ключ API Holodex**, щоб налаштувати його.

### 📺 Як я можу видалити рекламу?
Реклама підтримує розробку додатка, але ви можете видалити її за допомогою покупки в додатку для більш плавного досвіду.

### 🔍 Як збільшити мініатюри або значки каналів?
Просто довго натискайте будь-яку мініатюру, значок каналу або зображення банера, щоб збільшити його.
