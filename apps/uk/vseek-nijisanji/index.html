Часті запитання (FAQ)

🎬 Як я можу приховати канали, які мене не цікавлять?

Перейдіть до Налаштування > Приховати канали та керуйте ними індивідуально. Залиште лише ті канали, які вас цікавлять.

🌐 Що робити, якщо я бачу помилки?

За замовчуванням додаток використовує спільний ключ API Holodex, який має обмеження доступу. Встановлення власного ключа API Holodex покращить стабільність та актуальність даних. Перейдіть до Налаштування > Встановити ключ API Holodex, щоб налаштувати його.

📺 Мені не подобається реклама. Чи можу я її видалити?

Так. Реклама підтримує додаток, але ви можете видалити її за допомогою покупки в додатку для безстресового досвіду.

  1. Увімкнути сповіщення: Торкніться значка дзвіночка на каналі свого oshi, щоб переконатися, що ви отримуєте сповіщення про трансляції.
