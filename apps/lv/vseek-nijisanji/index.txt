- **Tiešraides grafika attēlošana**: Skatiet Nijisanji Liveru tiešraides, gaidāmās un arhivētās tiešraides vienuviet.
- **Reāllaika paziņojumi**: Saņemiet push paziņojumus par pārsteidzošām partizānu tiešraidēm vai pēkšņām sadarbībām, lai nekad nepalaistu garām savu oshi tiešraidē.
- **Kanālu slēpšana**: Paslēpiet kanālus, kas jūs neinteresē, lai pielāgotu savu laika joslu.
- **Holodex API atslēgas atbalsts**: Iestatiet savu API atslēgu, lai uzlabotu stabilitāti un uzticamāk iegūtu jaunākos tiešraides datus.

- **Pielāgoti attēlošanas režīmi**: Pārslēdzieties starp liela sīktēla režīmu, saraksta režīmu, kompakto režīmu un citiem atkarībā no jūsu vēlmēm.

### 📢 Kā es saņemu paziņojumus par tiešraidi?
Pieskarieties zvana ikonai katrā kanālā un iestatiet to uz “IESLĒGTS”, lai saņemtu paziņojumu, tiklīdz sākas tiešraides.

### 🎬 Kā es varu paslēpt kanālus, kas mani neinteresē?
Dodieties uz **Iestatījumi > Paslēpt kanālus** un pārvaldiet tos individuāli. Saglabājiet tikai tos kanālus, kas jums ir svarīgi.

### 🌐 Kas man jādara, ja redzu kļūdas?

Jā. Reklāmas atbalsta lietotni, taču jūs varat tās noņemt, veicot pirkumu lietotnē, lai nodrošinātu bezstresa pieredzi.
